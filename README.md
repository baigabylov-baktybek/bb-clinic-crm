# BB Clinic CRM

Административное приложение для управления внутренним конвейером BB Clinic: заданиями, персоналом, кабинетами, оборудованием, услугами, складом и финансовыми показателями.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Telegram-бот администратора

Отзовите опубликованный токен через `@BotFather`, получите новый и сохраните его только в локальном `.env` по примеру `.env.example`. Затем запустите:

```bash
npm run bot
```

После выбора роли бот принимает карточки клиентов. Если отчётов нет дольше одной минуты, он напоминает администратору и повторяет напоминание не чаще одного раза в три минуты.
